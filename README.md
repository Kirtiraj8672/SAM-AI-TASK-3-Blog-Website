# 📝 Blog Website

A responsive Blog Website developed using **HTML**, **CSS**, and **JavaScript**. The website features a modern homepage, navigation bar, blog cards, search bar, category buttons, and responsive design.

This Blog Website was developed as part of my **Web Development Internship at SAM AI Technologies**. It demonstrates frontend development skills by creating a clean, responsive, and user-friendly blog interface.
